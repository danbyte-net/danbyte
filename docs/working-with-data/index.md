# Working with data

Day-to-day tools that apply across every page - getting the big picture,
shaping the tables to what you need, and moving data in and out.

## In this section

| Page | What it's for |
|---|---|
| [The dashboard](../features/dashboard.md) | The at-a-glance home screen of counts, charts, and status. |
| [Saved views & filters](../features/saved-views.md) | Name a search and its filters - including advanced filter expressions - and share it with your team. |
| [Table columns](../features/table-preferences.md) | Show, hide, and reorder columns on any list - your choices stick. |
| [Exporting tables](../features/exporting-tables.md) | Download what's on screen as a spreadsheet. |
| [Import & export](../features/import-export.md) | Bulk-load and dump inventory as CSV/JSON, with dry runs. |
| [Printing labels](../features/label-templates.md) | Server-rendered PDF labels sized to the label stock. |
| [Documents](../features/documents.md) | Attach files and links to any object. |
| [Journals](../features/journals.md) | Free-form operator notes on any object. |
| [Change log](../features/change-log.md) | The automatic who/what/when audit trail. |
| [Object numbers (IDs)](../features/object-numbers.md) | Short human-readable #ids next to the UUIDs. |
| [Background jobs](../features/jobs.md) | What the workers and scheduler are doing right now. |
